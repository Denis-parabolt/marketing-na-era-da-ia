# Comece aqui: leve o kit para a sua IA

A ferramenta de IA responde melhor quando sabe com quem está falando. O caminho mais curto é dar a ela
um arquivo de contexto do negócio, uma vez, e deixar esse arquivo valer para toda conversa.

## Passo a passo

1. Abra o [modelo de contexto do negócio](CONTEXTO-do-negocio.md), copie para um editor de texto e
   preencha os sete blocos. Frase curta, fato, sem adjetivo. É a Ficha 13 do curso.
2. Cole o texto na sua ferramenta como instrução permanente:

| Ferramenta | Onde colar |
|---|---|
| Claude | Projetos, campo de instruções do projeto |
| ChatGPT | Projetos, ou Instruções personalizadas |
| Gemini | Um Gem, no campo de instruções |
| Copilot | Um agente, nas instruções |
| Claude Code ou Codex | Um arquivo `CLAUDE.md` ou `AGENTS.md` na pasta do negócio, com o mesmo texto |

3. Toda conversa nova passa a começar com esse contexto. O briefing CLARO fica mais curto, porque o
   Contexto e os Limites já estão lá.
4. Guarde as fichas preenchidas na mesma pasta. Quando pedir uma pauta, cole a Ficha 04 (brief de marca);
   quando pedir uma campanha, cole a Ficha 06 (briefing de campanha). A IA trabalha melhor com o que você
   já decidiu.
5. Reescreva o contexto quando o negócio mudar. Contexto velho produz resposta velha.

## Três regras que o arquivo não dispensa

- **O checklist de revisão humana** roda antes de qualquer saída virar post, anúncio ou resposta. A IA
  escreve com a mesma confiança quando acerta e quando inventa.
- **Dado de cliente, documento, planilha e senha nunca entram** na conversa. O bloco 6 do contexto lista
  o que fica fora; a lista completa está em [checklists](../checklists/).
- **Quem publica assume.** A IA não assina.
